# Design examples

Looks from the September 2026 mockup round, kept in case another one is ever
wanted. They are **design examples only**: colors, type, spacing and how
components look. Layout and functionality are decided when each screen is
built, not taken from these pictures.

| Image | Look | Status |
|---|---|---|
| `iron.png` | Iron (option B) | Chosen: the default family, `src/core/design-system/tokens/families/iron.ts` |
| `chalk.png` | Chalk (option A) | Also a family, `src/core/design-system/tokens/families/chalk.ts` |
| `plate.png` | Plate (option C) | Example only, not implemented |

Each image shows a logging screen and a progress screen, in light and dark.
The icons are placeholders and the numbers are sample data.
